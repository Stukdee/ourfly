## 克隆项目：

这有什么好教的，不讲啦！

## 构建与编译：

```bash
mkdir build
cd build
cmake ..
make
```

## 运行：

```bash
./ourfly
```

## 操作说明：

上下左右 或者 wasd 键移动

z 或者 m 键发射子弹
