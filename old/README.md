## 克隆项目：

这有什么好教的，不讲啦！

## 环境配置：

```bash
python3 -m venv .venv
source ./.venv/bin/activate
pip3 install pyxel
```

## 运行：

```bash
python3 main.py
```

## 操作说明：

上下左右 或者 wasd 键移动

z 或者 m 键发射子弹
